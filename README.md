# Trabajo Práctico N°1 – Cliente/Servidor con Java Sockets

Este proyecto implementa un sistema simple de comunicación **Cliente-Servidor** utilizando **Java Sockets**.  
El **Cliente** envía dos números y una operación matemática al **Servidor**, y el **Servidor** devuelve el resultado.

---

## 🚀 Instrucciones de ejecución

### 1. Compilar los programas
En la consola, dentro de la carpeta del proyecto:
```bash
javac Servidor.java
javac Cliente.java
